## Alcance y decisiones

Python y entornos locales ya gestionados; imports de motores originales,
código nuevo separado. Sin cambios en `nexus0/`, campañas certificadas,
hardware ni segundo bus. Ningún examen histórico se reabre. Los nuevos
estudios fijan contratos, semillas, controles, puerta y hashes antes de medir.
La validación nueva se distingue de desarrollo y de exámenes históricos.
No convertir una prueba técnica en evidencia de ventaja científica.

El trabajo se divide en pistas sin archivos compartidos. El coordinador
mantiene roadmap y handoff; cada implementador conserva contrato, pruebas,
trazas reales, auditoría y resultado. Revisiones cruzadas antes de congelar.
No se crean commits, se borran resultados ni se instalan dependencias globales.

## Recursos y límites de ejecución

Groq es la primera opción autorizada. Clave solo leída dentro de scripts,
nunca impresa ni copiada a prompts, logs o cachés. Sin Google, fallback de
ExperientialLabs ni cambios de facturación. D tiene techo inicial de 240
intentos API y 150.000 tokens observados; pausas ante cuota y recibos por
hash. Si el proveedor bloquea la cuota, conservar el punto de reanudación;
no suponer que un error API equivale a una decisión del modelo.

Los simuladores se ejecutan con imágenes locales, sin descargas ni acceso
a exámenes sellados. Terminal local con logs reales para nuevos estudios.
5.9 P2 queda preparado pero fuera de este encargo. CRECE permanece cerrada
roja. SimpleQA conserva su preflight y examen cerrado; no se lanza la campaña
grande detenida. No hay publicación externa al terminar.
