# Public attribution and privacy

This snapshot uses RxLabs / Nav. Personal names and home paths have been
removed from current public text and metadata, including nested archival
containers. Some historical files therefore differ from their original frozen
bytes. Their embedded manifests/signatures are retained as original provenance,
not certificates of this edited snapshot. SOURCE-MANIFEST.json describes this
public snapshot. Scientific measurements were not rerun or relabelled.

Previous Git commits, tags and independently downloaded copies are not rewritten
by this release. A clean current snapshot does not erase historical identities.
The 5.8.2 export inventory gives source and public hashes for the selected new
files; archived negative results remain negative.
