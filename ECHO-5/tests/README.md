# Pruebas de ECHO-5

Aquí se añadirán pruebas `test_*.py` con unittest cuando se implemente el primer
módulo. `make test` devuelve código 2 mientras no exista ninguna. No se
considera un banco vacío una validación del agente.

Las pruebas ordinarias deben funcionar sin GPU, red, LLM ni credenciales.
Los ensayos científicos tendrán contratos, presupuestos y recibos separados.
