# Contributing to echo-nexus

echo-nexus 1.5 is a beta development tool. RxLabs welcomes volunteer developers
interested in terminal interfaces, provider compatibility, development worlds,
reproducible training and evaluation of ECHO.

Open an issue with expected behavior, actual behavior, harness version and
operating system. Include a minimal redacted log or screenshot when useful.
Do not upload API keys, private model files, engine code or reserved exam data.

Fork this repository and submit a pull request with the change's purpose and
relevant verification. Run the harness tests described in README. Backends use
the documented protocol and label simulations, fixtures and archived results
accurately. A process exiting successfully is not a benchmark result.

This repository contains only the MIT harness. ECHO core development and training
access must be coordinated separately with RxLabs; installing the beta does not
grant access to the engine or private exams.
