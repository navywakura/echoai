# Identidad oficial de echoAI

Designado por el responsable del proyecto el 22 de septiembre de 2026.
El símbolo blanco sobre negro es el logo oficial del **agente echoAI**,
incluido ECHO-4. No sustituye la R de la marca general RxLabs.

Fuente canónica: [echo-ai-agent-logo.png](../../../echo-ai-agent-logo.png),
PNG de 2000 × 2000, derivado público sin metadatos personales. El original se conserva sin cambios
en el laboratorio; los píxeles comprimidos IDAT de esta copia son idénticos.

SHA-256 original privado: `bdfcf084c25a33aa64dd66fc260513fc265d3962cb233b1dd076ded475338cbd`.
Hash público y prueba de píxeles conservados: [PUBLIC-METADATA.json](PUBLIC-METADATA.json).

Las versiones pequeñas deben conservar encuadre, proporciones, fondo negro
y trazos blancos, sin rediseño, recorte ni reinterpretación generativa.
No se concede una licencia de marca por publicar estos archivos; la revisión
de derechos de distribución permanece en E4-RELEASE-1.

Tamaños PNG: 16, 32, 48, 64, 128, 180, 192, 256, 512 y 1024 píxeles.
`favicon.ico` contiene 16/32/48 píxeles. Regeneración mecánica con ImageMagick:

```bash
bash assets/brand/echoai/generate.sh
```

El original no se reescribe. El resultado depende de la versión de
ImageMagick; son derivados para presentación, no evidencia experimental.

Usos: README del agente, página `/echoai`, documentación ECHOAI, artículos
y futura ficha autorizada de distribución. El favicon R permanece en las
demás secciones del laboratorio. La identidad visual no es un certificado
científico ni anuncia que DREAM-1 esté cerrado.
